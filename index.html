So wird gezählt

Die Tabelle folgt dem IBJJF-Regelwerk. Eine Position zählt erst, wenn sie drei Sekunden gehalten wird.

  1. Bei Gleichstand entscheiden zuerst die Punkte, dann die Vorteile, dann die Strafen.
  2. Ein Vorteil gibt es für fast erreichte Punkte oder eine gefährliche Submission.
  3. Guard Pull bringt keine Punkte, ist aber erlaubt.
  4. Welche Hebel an Knie und Fuß erlaubt sind, hängt von Gurt, Alter und Gi/No-Gi ab.

ADCC, AJP und andere Verbände werten anders. Vor einem Turnier immer das aktuelle Regelwerk lesen: ibjjf.com
